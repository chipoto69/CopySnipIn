# 03-01 Plan: Provider Fixtures And Domain Math

**Phase:** 03-provider-fixtures-domain-math
**Status:** Executed
**Requirements:** MATH-01, MATH-02, MATH-03, MATH-04, MATH-05, MATH-06

## Goal

Prove provider parsing and core financial calculations through deterministic
fixtures and pure tests before later worker phases depend on them.

## Tasks

1. Add sanitized Polymarket fixtures for leaderboard, positions, trades, empty,
   malformed, and pagination-related parser behavior.
2. Add sanitized Pyth Hermes fixtures for parsed price updates and malformed
   payload behavior.
3. Add typed Polymarket parser functions for leaderboard, positions, and trades.
4. Add typed Pyth parser functions with Decimal price/confidence decoding.
5. Add domain metric functions for Sharpe ratio and max drawdown.
6. Add qualification filtering with exact validation-contract boundaries.
7. Add pure Decimal paper-accounting primitives for BUY/SELL, realized PnL, and
   mark-to-market portfolio value.
8. Verify the full project gate and zero-execution safety regression.

## Out Of Scope

- Live Polymarket polling.
- Live Pyth streaming.
- Provider retries/backoff loops.
- Scanner/tracker/simulator service loops.
- Persistence writes for parsed or calculated data.
- API/dashboard read models.
- Execution-capable trading paths.
