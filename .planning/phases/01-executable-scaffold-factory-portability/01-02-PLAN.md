| HTTP client -> `/health` | External local caller receives scaffold health metadata. |
| Source tree -> safety scan | Tests inspect source for execution-capable affordances. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-1-03 | Information Disclosure | `/health` | mitigate | `/health` must return `mode=scaffold` and mark scanner/tracker/simulator/Pyth/dashboard as `not_implemented` instead of healthy/ready. |
| T-1-04 | Information Disclosure | Smoke output | mitigate | Smoke modules print fixed scaffold strings only and do not read or echo `.env`, `DATABASE_URL`, `REDIS_URL`, API keys, webhook URLs, or tokens. |
</threat_model>
