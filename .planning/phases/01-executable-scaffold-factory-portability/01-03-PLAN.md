<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer shell -> `.factory/init.sh` | Setup script resolves a checkout and may create/check local infrastructure. |
| Factory runner -> `.factory/services.yaml` | Service commands start, stop, and healthcheck local processes. |
| `.env` file -> setup output | Secret-bearing local file must not be printed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Elevation of Privilege | Factory service commands | mitigate | Factory service starts only run scaffold modules and `uvicorn copysnipin.main:app`; do not add execution-capable commands, signer clients, order placement, funding, or relayer targets. |
| T-1-02 | Tampering | `.factory/init.sh`, `.factory/services.yaml` | mitigate | Replace absolute checkout paths with Git/script root discovery and add tests proving the old path is absent. |
| T-1-03 | Spoofing | Worker healthchecks | mitigate | Worker/dashboard healthchecks run scaffold module smoke commands; API health remains `/health`; no deferred system is reported as implemented. |
| T-1-04 | Information Disclosure | `.factory/init.sh` output | mitigate | `.env` is checked by file existence only; setup must not print secret values or read the file contents. |
</threat_model>
