<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Polymarket API or fixture payload -> scanner provider | Untrusted read-only provider data enters typed scanner status objects. |
| Provider status -> logs/heartbeats | Provider errors and URLs can leave process memory through diagnostics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-04-01-01 | T | `copysnipin.hermes_scanner.provider` | mitigate | Parse all provider payloads through Phase 03 typed parsers and surface malformed data as degraded status. |
| T-04-01-02 | D | provider retry loop | mitigate | Bound retries and page traversal; inject fake sleepers for tests and avoid unbounded loops. |
| T-04-01-03 | I | provider diagnostics | mitigate | Persist/log compact redacted status only; never store secret-bearing headers or raw tokens. |
</threat_model>
