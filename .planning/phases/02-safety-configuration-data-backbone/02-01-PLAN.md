<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> settings | Untrusted env values cross into typed application config. |
| settings/errors -> logs/API/dashboard | Secret-bearing config errors can leave process memory. |
| docs/examples/factory -> operator runtime | Example config can imply unsafe active capability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | I | `copysnipin.config` | mitigate | Use Pydantic Settings with redacted error formatting; never log raw `ValidationError` input. |
| T-02-02 | I | `copysnipin.security.redaction` | mitigate | Centralize DSN/token/webhook/private-key-like redaction and test it directly. |
| T-02-03 | E | `copysnipin.safety` and factory scripts | mitigate | Static scan active source/routes/scripts for execution-capable terms and imports. |
| T-02-04 | S/T | `.env.example`, environment docs, services YAML | mitigate | Classify disabled/future env variables separately from active v1 settings and test contract drift. |
</threat_model>
