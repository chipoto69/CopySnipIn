<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> settings | Untrusted env values cross into typed application config. |
| settings/errors -> logs/API/dashboard | Secret-bearing config errors can leave process memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | I | `copysnipin.config` | mitigate | Use Pydantic Settings with redacted error formatting; never log raw `ValidationError` input. |
| T-02-02 | I | `copysnipin.security.redaction` | mitigate | Centralize DSN/token/webhook/private-key-like redaction and test it directly. |
| T-02-03 | E | `copysnipin.config` | mitigate | Keep execution-adjacent variables classified outside `ActiveSettings` startup requirements. |
</threat_model>
